# Security Policy

Kuito is a pre-release research framework and has **no production support or stable security-release policy** yet.

Please **do not publish undisclosed vulnerabilities in a public issue**. Use the repository's private vulnerability reporting feature, if enabled, or contact the maintainers through an authenticated private channel.

Do not assume the project is safe for sensitive production workloads until its runtime, native capabilities and release distribution have been audited.
