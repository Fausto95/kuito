# Start building with Kuito

Kuito turns TypeScript, TSX and CSS into native iOS and Android interfaces.
Use it to build screens with native controls, reactive state and device APIs.
It is experimental: APIs and generated projects may change.

## Start with a working screen

Follow [Create your first app](../../../docs/apps.md) to install the tools,
run the starter and replace its home screen. Then learn
[screen layout](../../../docs/primitives.md), [state](../../../docs/reactivity.md)
and [styling](../../../docs/styles.md).

## How to use these docs

Guides teach a task from beginning to end. Components and APIs explain when
to use each export, show a complete example and list its exact props or
signature. Styling covers the supported CSS dialect. CLI covers commands and
options. Architecture explains implementation choices for contributors.

Examples import from `kuito`, `kuito/config` or `kuito/tests`. They are checked
against this checkout. URLs on `example.com` are placeholders for your server;
asset paths are files you supply. Fragment examples are explicitly labeled.
